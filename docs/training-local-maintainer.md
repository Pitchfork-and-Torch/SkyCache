# Local maintainer training (half-day outline)

## Goals

After training, a maintainer can:

1. Power the hub on/off safely.  
2. Confirm phones can open the portal.  
3. Read admin storage and battery status.  
4. Copy a USB content pack into the hub (with a volunteer script).  
5. Know what **not** to do (no commercial satellite hacks; no medical advice claims).

## Module 1 - What SkyCache Nexus is (20 min)

- Offline library + weather pictures + notices  
- Optional multi-node mesh (several hubs, same library)  
- Store-and-forward + community mesh - **not** free commercial broadband  
- Legal: receive free public signals / open files only; mesh only on legal Wi-Fi/ISM  
- Admin: mesh peers, gateway quota, disaster mode (emergency/health first)  

## Module 2 - Physical plant (30 min)

- Battery, solar, fuses  
- Antenna is fragile - do not climb alone  
- Keep enclosure dry  

## Module 3 - Portal & admin (40 min)

- Connect to WiFi  
- Browse categories  
- Language switch  
- Admin PIN (change from default)  
- What "stale" weather means  

## Module 4 - Hands-on failure drills (40 min)

- Unplug power -> restore  
- Full disk story -> what gets deleted first  
- Wrong WiFi password / open network etiquette  

## Module 5 - Content updates (30 min)

- USB folder with `manifest.json`  
- Never install random unknown apps on the hub  
- Log what was added in a paper notebook  

## Certification

Maintainer demonstrates:

- [ ] Phone portal access  
- [ ] Admin status screen  
- [ ] Safe power cycle  
- [ ] Explains "not Starlink" to a peer
