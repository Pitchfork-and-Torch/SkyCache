Offline maps (operator guide)

This package is a license-clean placeholder + guide for offline maps. Ship real MBTiles or OSM extracts only when the license (e.g. ODbL attribution) is recorded in the package passport. Not a commercial map service. Not free broadband.

How villages use maps packs

  1. Obtain an open extract (e.g. Geofabrik region) or self-built MBTiles.
  2. skycache skybrary import-folder ./maps --license "ODbL" --subjects maps,mbtiles --ingest
  3. Or place region.mbtiles in a package and: skycache blobs put region.mbtiles
  4. Build kit: skycache skybrary pack --profile maps-offline

Priority

Maps rank below Emergency and Health under disk pressure. The maps-offline profile reserves room for life-safety packs.
